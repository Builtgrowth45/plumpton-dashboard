Plumpton Revival Campaign Dashboard · Built Growth · Last updated: 1 April 2026

1. What this app does

The Plumpton Revival Campaign Dashboard ("the App") is an internal analytics tool built by Built Growth. It aggregates campaign performance data from Meta Ads, Google Analytics 4, and Google Search Console into a single view for the Plumpton Revival event team.

2. Data we access

When you connect your accounts, the App requests read-only access to:

  • Meta Ads — campaign performance metrics (spend, impressions, clicks, CTR), ad set data, and pixel event counts via the Marketing API.
  • Google Analytics 4 — session counts, traffic sources, pageviews, bounce rate, and session duration.
  • Google Search Console — search queries, clicks, impressions, CTR, and average position.

3. Data we store

The App does not store any personal data or access tokens on any server. All data is:

  • Fetched in real-time from the respective APIs
  • Displayed only in your browser session
  • Discarded when you close the page or your session expires

No cookies, databases, or server-side storage are used. Access tokens exist only in browser memory for the duration of your session.

4. Data sharing

We do not sell, share, or transfer any data to third parties. The App only communicates with the official Meta Graph API, Google Analytics Data API, and Google Search Console API.

5. Your rights

You can revoke the App's access at any time:

  • Meta — Go to Facebook Settings → Apps and Websites → remove "Plumpton Dashboard"
  • Google — Go to myaccount.google.com → Security → Third-party apps → remove "Plumpton Dashboard"

6. Data deletion

Since we store no user data, there is nothing to delete. If you wish to formally request data deletion, visit our data deletion page or email kyle@builtgrowth.com.
